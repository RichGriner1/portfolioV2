## Workflow

This is the rule any agent (or future-Richard) reads before producing social content. Update *here* when something drifts — don't fix outputs in place and forget.

### Brainstorm batches (single source of truth)

Each brainstorm session produces **ONE** batch file at `content/social/<pillar>/YYYY-MM-DD-<topic>-batch.md`. The batch contains every idea from that session. Inside, per idea:

- A numbered heading (becomes the anchor target for calendar rows)
- A **LinkedIn** section — the complete post, ready to copy-paste
- A **Twitter** section — the complete thread (or standalone tweet), ready to copy-paste
- A **Notes** section — case-study tie, optional graphic concept, anything internal that doesn't get pasted

**No individual per-post files.** The batch IS the source of truth. The calendar above points to anchors inside the batch.

### One body, two formats

LinkedIn and Twitter share substance but differ on:

- **Hook** — Twitter opens with the surprising claim; LinkedIn opens with the situation.
- **Line breaks** — Twitter every 1–2 sentences; LinkedIn paragraphs of 2–4.
- **Tone room** — LinkedIn slightly more measured.

Both formats land **final and copy-paste-ready** in the batch. No intermediate "body" section. No "LinkedIn-hook + Twitter-hook + content" split. Just the two final formats, sectioned, ready to paste.

### Cadence (current: launched 2026-06-27)

- **Sat — blog day.** One long-form post per week to the portfolio. Promoted from `content/drafts/<pillar>/` to `content/published/<pillar>/YYYY-MM-DD-<slug>.md` (copy, not move). Blog kicks off each week's social rotation.
- **Sun–Fri — social, daily.** Six tweets per week. Threads land mid-week (Tue/Wed/Thu); standalones the other days.
- **Threads — 1–2/week.** Strong threads get top-of-week (Tue) or mid-week (Wed) slots. Twitter-only.
- **LinkedIn — 2/week, Mon + Wed.** Decoupled from threads. When a Wed thread + Wed LinkedIn happen to be the same idea, they run together; otherwise they're independent posts.
- **Standalones — 4–5/week** on non-thread days (Twitter).
- **Edit + schedule cycle.** Friday or Saturday: voice-check the coming week's rows + lock status to `ready`. Sunday: copy from the batch into composers and post throughout the week as scheduled.

### Topic rotation (don't repeat themes back-to-back)

Six clusters to cycle through:

- **Research-before-design** — MU §1 (Research-first), VI §3 (Capture-then-annotate), VI §4 (Steal from outside)
- **Identity / patterns** — MU §2 (Patterns not pixels), VI §1 (Speed without identity)
- **Briefing / leadership** — VI §2 (Real client), VI §5 (Three directions), MU §3 (Vague brief)
- **Interaction** — MU §4 (Delay rule)
- **Maturity / system** — MU §5 (Collective commitment)
- **AI tooling** — AID2C (all standalones from the ai-design-to-code flow piece)

**Rule:** consecutive posts should pull from different clusters. A research-first standalone Sunday → consultancy-briefing standalone Monday → identity standalone Tuesday → AI-tooling standalone Wednesday. Mix.

When extending the calendar past the pre-mapped 4 weeks, follow the same rotation: pull the next unused standalone from the cluster that hasn't surfaced in the previous 2–3 posts. Threads scheduled mid-week (Wed or Tue) every other week.

### Status meanings

- **draft** — still being shaped. Voice may still be wrong, copy may still get edits.
- **ready** — reviewed, voice-checked, copy is final. Ready to paste.
- **posted** — live. Note the date in the batch file's idea section + update the row here.

### Adding ideas

**To an existing batch:** append a numbered heading with LinkedIn + Twitter + Notes. Add a calendar row pointing to the new anchor.

**Starting a new batch:** create `content/social/<pillar>/YYYY-MM-DD-<topic>-batch.md`. Write each idea as: numbered heading → LinkedIn → Twitter → Notes. Add calendar rows pointing to each anchor.

**A blog feeds a batch:** when a long-form post publishes, the syndicator agent reads it and produces a new batch file with 3–5 ideas pulled from the piece. Same format as a brainstorm batch.

### Format check (use this before scheduling)

- [ ] Each idea has both LinkedIn AND Twitter sections, complete copy in each
- [ ] LinkedIn opens situation-first, 150–250 words, soft / no pitchy CTA
- [ ] Twitter opens claim-first, 6–9 tweets, last tweet has the long-form link if one exists
- [ ] No banned phrases per [voice.md](../voice.md): no *leverage / unleash / robust / seamless / delve / navigate / X isn't Y it's Z / Not just X but Y*
- [ ] No "DM me" / "available for projects" on LinkedIn (full-time job)
- [ ] Calendar row links the right anchor and `status` matches reality
