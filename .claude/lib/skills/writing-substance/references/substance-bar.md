# Substance bar: is it worth reading?

The bar every piece clears before tone matters. From `content/voice.md`, generalized.

## The three things every piece needs
1. **One takeaway, stated.**
   - Write the takeaway as a single sentence *before* checking the piece. If you can't, the piece has no point yet.
   - Then find that sentence *in the text*. If the reader has to reconstruct it from a story, it's not stated — revise.
   - A takeaway that needs two sentences is usually two posts, or one that isn't focused.
2. **A real "so what," on the page.**
   - Name *why it matters* in words. "This is why X beats Y" / "which means you can stop doing Z."
   - Implied so-what (the story "shows" it but never says it) fails for most formats — say it.
3. **Non-obvious.**
   - If a competent peer in the field already knows it, either go a layer deeper or cut it.
   - **Process / build-in-public posts are not exempt.** "Here's my workflow" is not automatically valuable — the value is the *non-obvious decision or result*, not the fact that a workflow exists.

## The three tests (in order)
- **"and?"** — after the last line, does an "…and?" have an answer already on the page? No answer → missing so-what.
- **screenshot** — would a practitioner screenshot this to keep, or send to a coworker? If not, it's filler.
- **subtraction** — if the piece vanished, would the reader lose anything? If not, don't ship it.

## Verdicts this produces
- **Fails takeaway** → *revise* (or *rewrite* if there's no point to salvage). Cite the missing takeaway.
- **Fails so-what** → *revise*: "the point is implied by the story but never stated — add the so-what line."
- **Fails non-obvious** → *revise* or *cut*: "a peer already knows this — what's the deeper cut?"
- **Passes all three** → substance is fine; hand to clarity/length + the language lens.
