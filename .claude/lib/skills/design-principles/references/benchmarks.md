# Benchmarks (reference vocabulary only)

From the AFI-FOUNDATIONS-MODERN frame (`node-id=2035-65`). These are **not a checklist** — an AI can't verify "does this look like Linear." Use them as shared vocabulary when describing a target quality, and as the gut-check baked into decision-filter question 6 ("Would Cursor, Granola, or Shopify make this decision?").

| Product | Reference for |
|---|---|
| **Cursor** | Compact controls · minimal navigation · density · spacing · restrained color · subtle shadows |
| **Granola** | Typography · hierarchy · dialogs · polished inputs · calm layouts |
| **Shopify** | Dashboards · cards · analytics · graphs · financial information · interaction polish |
| **Clerk** | Authentication flows · cards · menus · dialogs · micro-interactions |
| **Vercel** | Page structure · tabs · command surfaces · developer tooling · minimal interfaces |
| **Notion** | Navigation hierarchy · information architecture · progressive disclosure · nested content |
| **Resend** | Menus · contextual palettes · dropdown composition · spacing |
| **Linear** | Interaction quality · responsiveness · precision · keyboard-first workflows |

**How to use:** when a design decision is ambiguous, ask which of these the surface should resemble, and borrow that quality — "this dashboard should read like Shopify's analytics (hierarchy before color), not a colorful-KPI dashboard." Don't cite benchmarks as pass/fail; cite the principle or anti-pattern they exemplify.
